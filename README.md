# CU Campus Fare Calculator (চবি ভাড়া ক্যালকুলেটর)

চট্টগ্রাম বিশ্ববিদ্যালয় ক্যাম্পাসের রিকশা, সিএনজি ও ই-কার ভাড়ার হিসাব।
ভাড়ার তথ্য: চাকসু কর্তৃক প্রকাশিত তালিকা অনুসারে।
লাইভ সাইট: https://mihossaincu.github.io/cu-fare/

## ফাইল
- `index.html`: মূল অ্যাপ
- `fares-template.csv`: গুগল শিটের শুরুর ডেটা (এখানকার ডেটা দিয়ে শিট তৈরি করুন)
- `manifest.json`, `sw.js`, `icons/`: ইনস্টল ও অফলাইন সুবিধা
- `robots.txt`, `sitemap.xml`: সার্চ ইঞ্জিনের জন্য

## GitHub Pages-এ প্রকাশ
1. রিপোজিটরি `cu-fare` (owner: mihossaincu) এ সব ফাইল ও `icons/` ফোল্ডার রুটে আপলোড করুন।
2. Settings → Pages → Source: `main` branch, `/ (root)`.
3. কয়েক মিনিট পর https://mihossaincu.github.io/cu-fare/ খুলবে।

## ভাড়া আপডেট (গুগল শিট)
1. Google Sheets-এ নতুন শিট বানান, `fares-template.csv`-এর ডেটা পেস্ট করুন। প্রথম সারি হবে: `from,to,rickshaw,cng,ecar`।
2. ফাঁকা ঘর মানে সেই বাহন নেই। ভাড়া লিখুন শুধু সংখ্যায়।
3. File → Share → Publish to web → শিট/ট্যাব নির্বাচন করে format হিসেবে **Comma-separated values (.csv)** নিন → Publish।
4. যে লিংক পাবেন (`.../pub?gid=...&single=true&output=csv`) সেটি `index.html`-এর `SHEET_CSV` ভেরিয়েবলে বসান।
5. শিট বদলালে কয়েক মিনিটের মধ্যে অ্যাপে আসবে (Google-এর ক্যাশের কারণে)। কোড বদলাতে হবে না।

যদি শিট লোড না হয় (ইন্টারনেট নেই বা লিংক ভুল), অ্যাপ `index.html`-এর ভেতরের শেষ সংরক্ষিত ডেটা দেখাবে।

### নতুন স্টপ যোগ করলে
- শিটে যোগ করলেই স্টপটি ক্যালকুলেটর ও তালিকায় আসবে।
- তবে CNG ও ই-কার চলাচলের অনুমতি `index.html`-এর `CG` ও `ecarOk` নিয়মে ঠিক করা আছে। নতুন স্টপের জন্য সেখানে যোগ করতে হবে, নইলে সেই স্টপের সিএনজি/ই-কার ভাড়া দেখাবে না।
- স্থানের ইংরেজি নাম চাইলে `EN` অবজেক্টে যোগ করুন।

## ক্যাশ
`sw.js`-এর `CACHE` সংস্করণ (`cu-fare-v4`) কোড বদলালে বাড়ান। শিটের ডেটা বদলালে এটি দরকার নেই।
